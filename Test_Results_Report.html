Q1 How do I reverse a list in Python?
⏱ 4.19s 📚 5 docs ✅ PASS
Answer
There are several ways to reverse a list in Python: 1. Using Slicing: old_list[::-1] Creates a new list with elements in reverse order. 2. Using reversed(): list(reversed(old_list)) Returns a reversed iterator, converted to a list. 3. Using .reverse(): old_list.copy().reverse() Reverses the list in-place on a copy. Trade-off: Slicing is most concise; .reverse() avoids creating a new list object for large lists. All methods create a shallow copy — use copy.deepcopy() for nested mutable objects.

Q2 What is the difference between a list and a tuple in Python?
⏱ 4.13s 📚 5 docs ✅ PASS
Answer
The main difference is mutability: • Lists [] — Mutable, can be modified after creation. Used for collections that may change. • Tuples () — Immutable, cannot be changed after creation. Can be used as dictionary keys. Additional distinctions: - Tuples can return multiple values from a function. - Named tuples (from collections) provide lightweight objects with named fields. - Lists are NOT hashable and cannot be dictionary keys; tuples can be. Example: my_dict = {(1, 2): "value"} ✅ | {[1, 2]: "value"} ❌

Q7 What is the difference between __str__ and __repr__ in Python?
⏱ 11.65s 📚 5 docs ✅ PASS
Answer
__str__ → Human-readable representation (for end-users). Called by str() and print(). __repr__ → Developer-oriented representation; ideally a valid Python expression to recreate the object. Called by repr(). Key rule: If only __repr__ is defined, it is used for both. If both are defined, __str__ takes priority for str() calls. class Point: def __str__(self): return f"Point at ({self.x}, {self.y})" def __repr__(self): return f"Point(x={self.x}, y={self.y})" Note: The backtick alias for repr() was removed in Python 3.

Q8 How do I use Python's *args and **kwargs?
⏱ 10.33s 📚 5 docs ✅ PASS
Answer
*args → Non-keyworded variable-length arguments; received as a tuple. **kwargs → Keyworded variable-length arguments; received as a dictionary. Rules: • *args must come before **kwargs in function definition. • Python 3 supports keyword-only args after *args: def f(a, *args, b=3, **kwargs) • Access kwargs like a dict: kwargs.get('name', 'default') Usage pattern: def my_function(*args, **kwargs): for arg in args: print(arg) for key, val in kwargs.items(): print(f"{key} = {val}")
